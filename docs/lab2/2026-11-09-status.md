# Lab2 FILE_AS_SQL 当前进度（2026-11-10）

实现已完成课程 FILE_AS_SQL 题目要求覆盖的 SQL 链路，并通过未修改的官方 `file_sql_basic.test`。开发目录是 Ubuntu WSL2 的 `/home/wangjiayi/seekdb`，分支 `my-lab`；Windows 的 `hw1-flights` 是另一份作业目录。实验代码在 SeekDB 源码中实现，不是在网页上操作。

## 完成内容

- `read_csv`、`read_json`、`read_ndjson`、`read_parquet` 和 `glob` 接入原生 `FILE_SCAN`，支持 Schema 推断、投影、批量读取、rescan、EXPLAIN、聚合、排序及 JOIN。
- CSV 支持命名选项、严格引号/UTF-8/行宽校验、BOM/CRLF/多行字段、重复或空表头规范化、NULL 与空串区分、确定性类型合并和位置错误。
- JSONL 支持扁平对象字段并集、缺失值补 NULL、原生标量类型、Unicode 转义、类型冲突和重扫；嵌套值不支持并按约定报错。
- Parquet 支持平面标量列、多 row group、NULL、PLAIN/dictionary、Snappy、DataPage v1/v2、日期时间、COUNT 元数据路径和真实列裁剪。嵌套、INT96、ZSTD 等未支持输入明确拒绝；footer/page/分配有界检查。
- `DESCRIBE SELECT` 文件表返回列元数据；`glob` 只返回受限目录内普通文件并排序。
- `COPY table/query TO CSV` 走原生查询链路，保留 NULL/空串区别，目标已存在时不覆盖，使用临时文件和原子发布。
- 文件输入只读；路径校验、目录 fd 锚定和 `openat2` 限制阻止越界/符号链接竞态；推断、执行和重扫校验文件指纹；对文件 SQL 绕过计划缓存复用。
